# NEXOS
A GUI named hedge for T-Watch2019 with touch screen.

Modify and Forked from sharandac https://github.com/sharandac/My-TTGO-Watch
to make it run on TTGO T-Watch2019 from LillyGO.
# Current situation
We have temporarily suspended development indefinitely. This means that usage or modification requires specialized skills,
some tools may no longer be available, and we will not be responsible for any damage to the equipment during installation.
# Solution
We recommend switching to My-TTGO-Watch from sharandac or another project that is still under development.
